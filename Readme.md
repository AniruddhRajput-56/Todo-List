# To-Do List Web App

A simple **To-Do List** web application built with **HTML, CSS, and JavaScript**.  
Add tasks, view them in a list, and delete tasks when completed.

---

## 📝 Project Overview

This project allows users to:

1. **Add a task** by typing in the input box and clicking the **Add Task** button.
2. **View all tasks** in a dynamic list.
3. **Delete tasks** individually using the **Delete** button next to each task.

It demonstrates basic **DOM manipulation** and **event handling** in JavaScript.

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the web app
- **CSS3** – Styling, layout, and basic animations
- **JavaScript** – Adding, deleting, and managing tasks dynamically
